Pengaturan Webhook

Masukkan URL Webhook Discord channel kamu untuk menerima notifikasi saat me-retweet.

Jika dimatikan, file besar akan dikirim sebagai link.
Cara Membuat Webhook Discord
  1. Buka Discord di PC/Desktop (atau mode desktop di HP).
  2. Klik kanan pada channel yang ingin kamu tuju, pilih Edit Channel.
  3. Pilih menu Integrations > Webhooks.
  4. Klik New Webhook.
  5. Ganti nama (opsional) dan klik Copy Webhook URL.
  6. Paste URL tersebut di kolom di atas.
